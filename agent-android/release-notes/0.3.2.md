## 0.3.2 (2026-10-23)

This agent has its own 0.x version line. It is not behind the Windows agent's 3.x.

### Bug Fixes

* **wipe:** *Wipe device* now erases phones on Android 14 and later (#178). Until now the console reported the wipe as started and the command as done, but Android refused the request a few seconds later and the phone kept working and reporting. Phones on Android 8 to 13 were not affected.
* **security:** on a fully managed phone, the person holding it can no longer change the hub URL (#178). Before, the *Advanced* section of the app let anybody type a different hub and save it, which took the phone out of management: the console only saw a device go offline. The field is now greyed out and shows the hub the phone reports to.

### What the person holding the device sees

* On a phone provisioned by QR code, the *Hub URL* field under *Advanced* is greyed out and labelled as set by provisioning. Nothing else changes.
* On a phone where the agent was installed as an ordinary app, nothing changes. The hub URL can still be edited there.

### What to do

* **Upload the 0.3.2 APK on the hub's *Android device provisioning* page (Agent APK)**, so phones you provision from now on start on it.
* Moving a fully managed phone to a different hub now takes a factory reset and a new QR code. A managed phone that came up without a hub (the 0.3.0 provisioning bug) can still be given one once.
* If a phone was ever wiped from the console and is still reporting, it was not erased. Wipe it again after it has updated to 0.3.2.
* Test a wipe on a scratch device first. A wipe has no undo.
