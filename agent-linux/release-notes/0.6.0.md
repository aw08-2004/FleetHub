## 0.6.0 (unreleased)

### Features

* **updates:** a machine that cannot reach GitHub now updates through its own hub. It looks for the signed manifest and the new build on GitHub first and on the hub's copy second (hub 1.192.0 or later), and checks both exactly as before: the release key for the manifest, the signed hash for the build. The journal says *reading the manifest through the hub* when it switches
* **updates:** a connection that never answers is given up after 10 seconds instead of holding each check for the whole timeout

### Notes

* No hub update is needed for anything else in this release. Against a hub older than 1.192.0 the second source answers 404 and the machine behaves as before
* A machine on an older agent that cannot reach GitHub cannot update itself to this one. Run the catch-up script in *docs/installation.md* ("PCs already stuck on an older agent") on it once
