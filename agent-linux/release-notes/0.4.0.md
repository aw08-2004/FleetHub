## 0.4.0 (unreleased)

### ⚠ BREAKING CHANGES

* **rollout:** deploy hub 1.146.0 or later before this agent. Signed telemetry needs hub 1.144.0 to check the signature (an older hub ignores the header, so the order is safe, but nothing is protected), and uninstall-on-delete needs hub 1.146.0 to send the `decommissioned` refusal. Leave Settings → Endpoint Security → *Only accept telemetry from enrolled agents* off until Administration → Onboarding → *Machines reporting without enrollment* is empty, which also waits on Android 0.3.0 ([#119](https://github.com/aw08-2004/Temp_Monitor/pull/119)) ([cdc939f](https://github.com/aw08-2004/Temp_Monitor/commit/cdc939f))
* **devices:** a Linux box on 0.3.0 or earlier is not removed when its device is deleted from the hub; it re-enrolls and comes back. A box that takes 0.4.0 is removed, including its enrollment identity and secret, so a deleted machine that should return has to be installed again with `install.sh --secret` ([#122](https://github.com/aw08-2004/Temp_Monitor/pull/122)) ([84863fc](https://github.com/aw08-2004/Temp_Monitor/commit/84863fc))

### Features

* **telemetry:** sign every report with the machine's own agent token, so another machine can no longer report under this one's name ([#119](https://github.com/aw08-2004/Temp_Monitor/pull/119)) ([cdc939f](https://github.com/aw08-2004/Temp_Monitor/commit/cdc939f))
* **devices:** uninstall the agent when its device is deleted with *Also uninstall the agent* ticked. After three `decommissioned` refusals in a row (about 30 seconds, or the next time the box is switched on) the agent starts a transient systemd unit, `fleethub-agent-uninstall`, outside its own cgroup, which removes the agent's unit, `/opt/fleethub/agent`, `/var/lib/fleethub/agent` and `/etc/fleethub`. The script is written to a root-only folder, never `/tmp`, and the recursive deletes only touch those known paths ([#122](https://github.com/aw08-2004/Temp_Monitor/pull/122)) ([84863fc](https://github.com/aw08-2004/Temp_Monitor/commit/84863fc))

### Code Refactoring

* **telemetry:** tidy the code that builds the bearer header after review findings on the signing change, with no change in behaviour ([#119](https://github.com/aw08-2004/Temp_Monitor/pull/119)) ([22f7193](https://github.com/aw08-2004/Temp_Monitor/commit/22f7193))

### Documentation

* This agent is on its own `0.x` line and is not behind the Windows agent's `3.x`. Linux machines still enroll with `install.sh --secret`; the onboarding wizard is Windows-only. `install.sh` is served from `main`, so its fix for a binary under a backslashed path (`3366fda`) is already live and is not part of this release.
* **Not run on a real box.** The uninstall script is unit-tested for what it writes and refuses, but no Linux machine has been watched removing itself (ROADMAP.MD, *Owed locally*, item 10).
