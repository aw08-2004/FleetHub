## 3.55.0 (unreleased)

### Features

* **sensors:** the agent installs the PawnIO driver itself when it is missing, so a PC installed without it gets its temperatures back without a visit. It downloads the same pinned file the installer uses, from GitHub first and from the hub's copy second, refuses anything whose hash does not match, and tries again every six hours if it cannot. Its log says *driver missing; running PawnIO setup* and then *driver installed; reopening the sensors*
* **install:** once this version is the stable agent, `agent-install.ps1` no longer starts the PawnIO setup from the script and leaves it to the agent. An endpoint-security behaviour engine could kill the installer at that step, which stopped onboarding with no error message

### Notes

* Until 3.55.0 is promoted to stable, the installer keeps installing PawnIO as before, because a first install always takes the stable agent
