## 3.53.0 (2026-11-23)

### ⚠ BREAKING CHANGES

* **rollout:** deploy hub 1.183.0 or later before this agent. Against an older hub it deploys exactly as 3.52.0 did and simply reports no steps ([#217](https://github.com/aw08-2004/FleetHub/pull/217))

### Features

* **packages:** report each phase of a package deployment as it starts and ends (every download, every step, the detection check) with its exit code and reason, so the console can show which step a machine is on and why one failed ([#217](https://github.com/aw08-2004/FleetHub/pull/217))
* **packages:** stop a deployment when an operator aborts it. The running step's program and everything it started are ended, the working folder is still cleaned up, and the result says *ABORTED from the console*. A step marked *continue on error* does not carry on past an abort ([#217](https://github.com/aw08-2004/FleetHub/pull/217))
* **packages:** mark where each step's output starts and ends in the live output stream, so the console can show one step's log on its own ([#217](https://github.com/aw08-2004/FleetHub/pull/217))

### Bug Fixes

* **remote:** follow a sign-in when the session was started on the *logon screen* entry of the Session picker. The view moves into the session the user signed in to, instead of staying on a logon screen nobody is looking at any more and showing black. A session pinned to a signed-in user, or to an RDP session's logon screen, still stays where it was put. Hub 1.182.0 already brings a relayed session back after a sign-in on its own; this covers the pinned case ([#170](https://github.com/aw08-2004/FleetHub/issues/170)) ([#216](https://github.com/aw08-2004/FleetHub/pull/216)) ([264f81a](https://github.com/aw08-2004/FleetHub/commit/264f81a))
* **telemetry:** log a report the hub refused as a warning that names the hub's reason, instead of as *Sent: ... Hub responded: 403*. A PC whose reports were all being refused used to look healthy in its own log ([#215](https://github.com/aw08-2004/FleetHub/issues/215)) ([#216](https://github.com/aw08-2004/FleetHub/pull/216)) ([306e1bc](https://github.com/aw08-2004/FleetHub/commit/306e1bc))
