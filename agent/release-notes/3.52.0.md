## 3.52.0 (2026-11-15)

### ⚠ BREAKING CHANGES

* **rollout:** deploy hub 1.180.0 or later before this agent. An agent running ahead of its hub is harmless: an older hub never asks it to send or back up a file

### Features

* **files:** send a single file, not just a folder, when an operator picks one for *Send to another computer…*. A picked file that has gone since the listing fails the copy by name instead of being left out
* **backups:** back up a single file named in a one-off backup from the Files tab. Until now a file there was skipped as "does not exist" while the run still reported success. The backup's excludes apply to a picked file as they do to every other
