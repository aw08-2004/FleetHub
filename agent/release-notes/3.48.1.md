## 3.48.1 (2026-10-22)

### Bug Fixes

* **terminal:** closing a terminal now ends its shell as well as everything the shell started. Until now only the shell's child processes were ended, and the `cmd` or PowerShell process itself was left for Windows to close with the console, which it does not always do promptly. No hub update is needed ([#175](https://github.com/aw08-2004/FleetHub/pull/175)) ([68e04e4](https://github.com/aw08-2004/FleetHub/commit/68e04e4))
* **terminal:** stop the agent from asking Windows for the exit code of a terminal whose shell is being closed at that same moment through a handle that may already be closed. A wrong exit code in the agent log was the worst that could happen, and it now fails cleanly instead ([#175](https://github.com/aw08-2004/FleetHub/pull/175)) ([68e04e4](https://github.com/aw08-2004/FleetHub/commit/68e04e4))
