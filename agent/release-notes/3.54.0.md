## 3.54.0 (unreleased)

### ⚠ BREAKING CHANGES

* **rollout:** deploy hub 1.187.0 or later before this agent. An older hub never sends If or Stop steps, and refuses the *not run* step state this agent reports for an untaken branch

### Features

* **packages:** run *If / Else* steps. The condition is checked on the machine when the deploy runs: its model, model name (Lenovo's *ThinkPad …* name from `Win32_ComputerSystemProduct`), manufacturer, SKU, chassis type, memory, processor, Windows version, build and release, architecture, BIOS version, domain, the hub's AD and custom-field values, a file, a registry value, an installed program, a PowerShell check (exit 0 true, 1 false), or the previous step's exit code. The branch not taken is reported *not run*
* **packages:** a condition this machine cannot answer fails the If step instead of running *Else*, unless the package says to run *Else*
* **packages:** run *Stop* steps: end the deploy as a success (detection is skipped) or as a failure with the package's message
* **packages:** skip downloading a payload whose download condition is false here. A step that would use it fails with that reason instead of running with a missing file
* **packages:** substitute `{model}`, `{model_name}`, `{manufacturer}`, `{sku}`, `{os_build}`, `{arch}` and `{hostname}` in step paths and arguments. A value that cannot be read fails the step
