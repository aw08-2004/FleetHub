## 3.46.0 (2026-10-17)

### ⚠ BREAKING CHANGES

* **rollout:** deploy hub 1.153.0 before this agent. The clipboard controls in the remote viewer ship with that hub, and the viewer only shows them when the agent's offer says `clipboard: true`, so an older hub simply never uses the new agent's clipboard and an older agent is never offered a paste it would drop. Clipboard sharing is gated on the existing `remote_control` permission, so nothing new has to be granted ([#150](https://github.com/aw08-2004/FleetHub/pull/150)) ([c70e93e](https://github.com/aw08-2004/FleetHub/commit/c70e93e))

### Features

* **remote:** carry text clipboard both ways during a remote session: a copy on the PC lands on the operator's own clipboard (or behind *Copy from PC* where the browser wants a click), and Ctrl+V on the picture sends the operator's clipboard first so the PC pastes the new text; works over WebRTC and the hub relay, up to 65,536 characters each way, and says so when longer text is cut ([#150](https://github.com/aw08-2004/FleetHub/pull/150)) ([c70e93e](https://github.com/aw08-2004/FleetHub/commit/c70e93e))
* **remote:** add *Send Cmd as Ctrl*, on by default from a Mac, so Cmd+C and Cmd+V reach the PC as Ctrl+C and Ctrl+V instead of Win+C and Win+V ([#150](https://github.com/aw08-2004/FleetHub/pull/150)) ([c70e93e](https://github.com/aw08-2004/FleetHub/commit/c70e93e))
* **service:** give the agent exe the FleetHub logo, which the ticket tray also takes its icon from instead of the generic system one ([#149](https://github.com/aw08-2004/FleetHub/pull/149)) ([e47b2ab](https://github.com/aw08-2004/FleetHub/commit/e47b2ab))
