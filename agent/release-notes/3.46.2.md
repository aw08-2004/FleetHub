## 3.46.2 (2026-10-20)

### Bug Fixes

* **tickets:** ticket screenshots reach the hub again. Every ticket from the tray arrived with "0/N screenshot(s)" and `Host desconocido` / `No such host is known` in the agent log on every PC, while the name resolved fine everywhere. The service was reading the person's account name in a way that left their limited sign-in token on the whole tray connection, and with that token the service could not look up the hub's name for a new connection. Only the ticket itself got through, because it reused the heartbeat's open connection.
