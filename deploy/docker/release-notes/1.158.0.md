## 1.158.0 (2026-10-20)

### Features

* **map:** devices that can be located but have no position are now listed under **Not located yet**, with what each one said the last time anybody asked -- for example *the location permission has not been granted on this device* -- and a **Locate** button for operators who may locate. Before this, a phone that had never returned a fix was missing from the map and from its search alike
* **packages:** a new **Install an Android app** step installs an APK on fully managed Android devices. A package with this step is Android-only: it can have no other step kinds, every payload must be pinned by sha256, and it takes no detection rule (the device checks that the app is installed itself)
* **packages:** a deployment aimed at a mixed group now keeps each package on its own platform. An Android package is not sent to a PC, and a Windows package is not sent to a phone; each such target is marked failed with the reason instead
* **posture:** Android devices are judged on the three checks a phone can answer -- screen lock (CIS 4.3), storage encryption (CIS 3.6) and a new **Security patch recent** check (CIS 7.3) -- instead of seven Windows checks that would always read unknown. The patch limit is a new setting, *Android security patches count as stale after* (90 days by default). PCs are unchanged

Needs Android agent 0.3.0 for the APK step, the posture checks, restart and the Wake-on-LAN relay; deploy the hub first.
