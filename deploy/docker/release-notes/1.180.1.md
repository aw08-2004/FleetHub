## 1.180.1 (2026-11-17)

### Bug Fixes

* **assistant:** stop queueing a package card that cannot succeed. A `create_package` call with no payload and no steps, or any other definition the Packages page would refuse, is now answered to the assistant in the chat with the reason and the fields it did send, and no confirmation card appears. Before this, you could confirm card after card and get the same error each time ([#212](https://github.com/aw08-2004/FleetHub/pull/212)) ([d1c281f](https://github.com/aw08-2004/FleetHub/commit/d1c281f))
* **assistant:** refuse a request identical to a confirmation card that is still waiting, and point at that card, so a model that keeps repeating itself no longer leaves a pile of identical cards to decline one by one ([#212](https://github.com/aw08-2004/FleetHub/pull/212)) ([d1c281f](https://github.com/aw08-2004/FleetHub/commit/d1c281f))
* **assistant:** read a request body sent as JSON text, and refuse one that is not an object by name, instead of dropping it and reporting a missing name ([#212](https://github.com/aw08-2004/FleetHub/pull/212)) ([d1c281f](https://github.com/aw08-2004/FleetHub/commit/d1c281f))
