## 1.186.0 (2026-11-24)

### Features

* **updates:** the hub now always updates from `main`. The **This hub's release channel** setting is gone from **Settings → Hub**, because the `beta` branch it could point at has been retired. Agent and client release channels are unchanged, and beta PCs keep getting beta agents

### Notes

* A hub that was set to **Beta** follows `main` once it runs this version. Nothing to change on it afterwards
* A hub still set to **Beta** and running 1.185.0 or older reads its updates from the `beta` branch, which stays at 1.185.0, so it does not reach this version by itself. Set it to **Stable** in **Settings → Hub** first; it then updates from `main` as usual
* To try a hub release before it reaches your production hub, pin a test hub's image to the exact version (`HUB_TAG=1.186.0`), then move the production hub's pin once it checks out
