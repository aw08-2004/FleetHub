## 1.162.0 (2026-10-21)

### Features

* **rules:** a new action, **Move to a PC folder**, files every PC the rule matches into the PC-tree folder you pick, or with *(no folder)* takes it out of every folder. So "every Windows 11 PC goes into *Win11*" is one rule instead of a job to repeat whenever a PC is upgraded or enrolled. A PC that is already in the folder is left alone, so a rule whose condition stays true does not refile it on every cooldown. It also works as a follow-up to a message's answer. The Active Directory half of the tree is unchanged and still read-only

### Security

* a rule that moves PCs needs **Manage PC tree**, the same permission filing by hand needs, because a folder can be a permission scope: moving a PC into a folder gives it to every permission group scoped to that folder, and taking it out removes it. The rule only ever moves PCs inside its author's own scope, and every move it makes is written to the audit log as a PC filing, naming the rule, so *who moved this PC* finds rule moves as well as hand ones. Manage rules alone cannot save one, and the AI rule drafter does not create them
* a folder that a rule moves PCs into cannot be deleted while that rule exists; the refusal names the rule

No agent update needed.
