## 1.178.0 (2026-11-03)

### Bug Fixes

* **rules:** a rule's toggle button says what clicking it does (*Disable* on an enabled rule, *Enable* on a disabled one), as Watchdogs already did. It used to show the rule's state, so an enabled rule's button read *Disabled*
* **devices:** *Wake all offline PCs* asks first, naming how many PCs it will wake, and says that it covers the whole fleet you can see, whatever search or filter is set. It now sits apart from *Export CSV* at the end of the toolbar
* **map:** *Live* is off when the map opens. Ticking it re-locates every online device every minute and shows each user a notice, so it is now a choice rather than a side effect of opening the page. Your browser remembers the last choice
* **machine:** the page header shows the same online/offline pill as Devices, with *Last seen* beside it
* **patches:** the Windows Update card lists updates installed outside FleetHub once per machine, with a count, and shows the first five lines behind a *Show all* toggle. It used to list every update separately, which on one fleet came to 216 lines with repeated KBs
* **patches, events:** the summary numbers at the top render as tiles again
* **machine:** BitLocker's *Read N times* line shows its text instead of the raw key `bitlocker.escrow.read_before`
* **console:** Delete buttons are red everywhere (Packages, Rules, Scripts, Watchdogs, Group policy, Device policy, Users, Invite links, Permission groups, Device groups), with a gap between them and Edit
* **devices, dashboard:** a *Last temp* and the *Hottest right now* tile at or over the hub's hot threshold are shown in red
* **machine:** disabled buttons look disabled. On the Network tab, a *No check-in since the packet was sent* card no longer stays up once the machine is online, and its explanation starts with a capital letter and is translated
* **provisioning:** the QR code is shown only after you click *Show code*, and the *provisioning_qr* Security audit line is written only then, not on every visit to the page. The component name appears once in the payload table instead of twice
* **machine:** the GPU tile is hidden on a machine that reports no GPU readings, instead of showing four dashes
* **copy:** sentence case in the sidebar (*Audit log*, *Permission groups*, *Invite links*, *Download client*, *Group policy*), *Agent version* instead of *Companion Version* on the machine page, *Matching now* on Rules, proper plurals on Device policy, no shouty capitals in the Backup tab, and proper dashes in place of ` -- ` throughout, in English, German and Spanish
* **machine:** the Firmware tab is easier to scan. What the machine reported and the search and buttons share one row, the second *Search this table* box is gone, every value control is the same width, a change that applied cleanly is one quiet line instead of a big card, and the *Apply changes* bar stays pinned to the bottom of the window while you have edits. Notices and plain lists across the console (firmware, wake, discovery, the BIOS image library) now render as tinted boxes and bullet-free rows, as they were meant to
