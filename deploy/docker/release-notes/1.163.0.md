## 1.163.0 (2026-10-21)

### Features

* **tables:** every table with more than five rows now has a search box above it and a **Filters** button that opens one filter box per column. Column filters combine with each other and with the search, so *Manufacturer* `dell` plus *OS* `windows 10` shows only the Dells still on Windows 10. The button counts the filters that are on, **Clear filters** resets them, and filters last for the browser tab. Pages that already had a search box (Devices, Audit log, Tickets, Users, Event logs, the Processes card) get the column filters without a second box
* **devices:** the column filters narrow the list itself, so the count, **Select all** and **Export** follow them
* **mobile:** on a phone every table is a stack of cards, one per row, each line labelled with its column. Device Groups, Users, Audit log and the other wide tables no longer drag the whole page sideways. Between 640 and 900 px a wide table scrolls inside its card instead

### Bug Fixes

* **search:** the Ctrl+K search opens centred near the top of the screen again, with its padding, instead of pinned to the top-left corner. On a phone it opens full width near the top
* **console:** margins and padding on the newer parts of the console (the Devices bulk bar, the Ctrl+K search) were being ignored and are now applied
* **patches, event logs, firmware:** their tables now use the console's table styling

No agent update needed.
