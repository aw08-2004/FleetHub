## 1.187.0 (2026-11-24)

### Features

* **packages:** a package can now **branch**. Add an *If / Else* step: it checks a condition on the machine and runs its *Then* steps or its *Else* steps. *Add Else if* chains another check, and If steps can sit inside each other up to four deep
* **packages:** conditions can test the machine's **manufacturer, model, model name** (Lenovo: *ThinkPad X1 Carbon Gen 11* rather than *21HD0012US*), **system SKU, serial, chassis type, memory, processor, Windows edition, version, build and release (23H2), architecture, BIOS version, computer name, domain**, its Active Directory OU and owner, and your **custom fields**. They can also check whether a **file or folder exists**, a **registry value** is there (or has an exact value), a **program is installed** (at a minimum version), or what a **PowerShell check** answers. *Exit code of the previous step* covers "if the last installer asked for a reboot". Combine any of them with *All of these*, *Any of these* or *None of these*, and groups inside groups
* **packages:** comparisons include *is*, *is not*, *contains*, *starts with*, *matches the pattern*, *is one of*, and *is more than / at least / less than / at most* for numbers and versions. Windows versions compare as versions, so 10.0.22631 is above 10.0.9200
* **packages:** a **Stop** step ends the deploy right there, either as *Succeeded, nothing to do here* (the detection check is then skipped) or as *Failed* with your message, for example *Unsupported model*
* **packages:** a payload can be set to **Only download on some machines**, so each model's driver pack reaches only that model
* **packages:** steps can use the machine's own values in paths and arguments: `{model}`, `{model_name}`, `{manufacturer}`, `{sku}`, `{os_build}`, `{arch}` and `{hostname}`
* **packages:** **Test on a machine** in an If step shows which branch a machine would take, from what the hub knows about it, with each check's actual value
* **packages:** the deployment view indents the steps inside an If under it, labels them *Then* and *Else*, and shows the branch that was not taken as *Not run*. *Step n of m* counts only the steps that run

### Notes

* If and Stop steps, download conditions and the `{model}` values need **Windows agent 3.54.0**. A machine on an older agent is not sent such a package: it fails at once with the version it needs, and *Retry failures* sends it once the agent has updated. Packages without them run on every agent as before. Deploy this hub before the agent
* If a machine cannot answer a condition (for example, its model could not be read), the If step **fails** rather than running *Else*, so the wrong driver pack is never installed on a machine nobody identified. To send unknown machines down *Else* instead, set *If the machine cannot tell* to *Run Else* on that step
* The machine itself decides each condition when the deploy runs. *Test on a machine* answers from the hub's last report, so it says *the machine decides* for file, registry and PowerShell checks and for Lenovo's model name
* Android packages cannot use If, Stop or download conditions
