## 1.193.0 (2026-11-26)

### Bug Fixes

* **onboarding:** Kaspersky Endpoint Security no longer stops onboarding on Windows. The onboarding script started a second PowerShell to run the agent installer, and Kaspersky's behaviour detection stopped the script at exactly that step. Run through `Invoke-Command`, the output simply ended after *Installing the FleetHub agent*, with no error, no agent, and a `C:\ProgramData\FleetHub-Onboard-…` folder left behind. The script now runs the installer in its own process
* **onboarding:** a failing agent installer is now always reported, with its reason, as *FleetHub onboarding failed*, including in a remote session. The onboarding code stays unused, as before

### Notes

* No change on the agent side and no new agent release. The Windows installer now ends with an explicit success code, so the onboarding script can tell a finished install from a failed one
* Kaspersky logs the blocked runs as event 4662 against `onboard.ps1`. A PC that failed this way can be onboarded again with the same command once the hub runs 1.193.0. Delete any `C:\ProgramData\FleetHub-Onboard-*` folders the failed runs left behind
