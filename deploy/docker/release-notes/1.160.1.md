## 1.160.1 (2026-10-21)

### Bug Fixes

* **assistant:** an AI provider that rejects a request no longer shows up as *"the AI provider refused the tool list -- this model or server does not support tool calls"* every time. That sentence was shown for **every** HTTP 400, so a model that had just run a dozen tool calls in the same conversation was blamed for not supporting them, and the provider's real reason was thrown away. The assistant now reads what the provider said: a conversation that has outgrown the model's context window says so and points at **Assistant memory size** in *Settings -> AI*; any other rejection shows the provider's own reason; only a rejection that is actually about tools still says the model does not support them. The reason is also written to the hub log

No agent update needed.
