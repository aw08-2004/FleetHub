## 1.160.0 (2026-10-21)

### Features

* **rules, watchdogs, device groups:** a group, a rule or a watchdog can now target PCs **by operating system** -- *Any Windows*, *Any Linux*, *Android*, or one of *Windows 11*, *Windows 10*, *Windows Server* and *Windows 8.1 and older*. It uses what the agent reported first and Active Directory only as the fallback, so a Windows PC that is not in AD is no longer left out of an "every Windows PC" group. The buckets are the same ones the Dashboard's **Operating systems** card counts, so the two always agree
* **rules:** new condition variables for the operating system as the agent reports it: **OS family** (`os.family`: windows / linux / android), **OS release** (`os.release`: windows_11, windows_10, windows_server, ...), **Operating system** (`os.name`, the full name), **OS version**, **OS build number** (`os.build`, so `os.build < 19045` works), **OS architecture** and **OS reported by** (agent or ad). *Operating system (from AD)* is unchanged

No agent update needed. A PC whose agent is too old to report its OS is placed by its Active Directory entry, as before.
