## 1.171.1 (2026-10-29)

### Bug Fixes

* **audit:** the **Audit Log** no longer closes the **Details** you opened every few seconds. It used to re-read the whole list whenever anything in the fleet changed, which on a busy hub was every 5 seconds; now it re-reads only when a new audit line is written, and every row you had open stays open
* **audit:** the list also waits while you select text in it, so copying a detail payload is no longer cut short by a refresh

### Notes

* New lines still appear on their own, at the top, within a few seconds of being written
* An operator who may not read security-level lines is no longer told when one is written, not even by the list refreshing
* No agent update is needed
