## 1.156.0 (2026-10-20)

### Features

* **console:** every page updates on its own when what it shows changes, with no refresh: a reply on a ticket, an alert raised or dismissed, a deployment advancing, a backup finishing, a setting changed by another operator, a device joining a group
* **console:** a machine going offline is shown within about five seconds of its online window running out, on the Dashboard, Devices, the machine page and the Map. A machine coming back shows on its first report
* **console:** "last seen 3m ago" and similar relative times keep counting while a page is open
* **console:** the topbar's Live pill shows on every page. It tracks the tab's one connection to the hub, and pages fall back to re-reading every 30 seconds while that connection is down
* **sidebar:** links granted or removed by a permission change appear or disappear without a reload, and live data follows the new scope straight away
* **console:** a page waits to refresh while you have an editor or dialog open or a setting you have not saved yet, so a live update never discards an unsaved edit

### Performance Improvements

* **console:** one live connection per browser tab instead of one per page. The Dashboard and machine page no longer open their own, so each tab holds one hub worker thread at most

### Bug Fixes

* **machine:** stop requesting a script that no longer exists on every machine page load
