## 1.170.2 (2026-10-29)

### Bug Fixes

* **remote:** Remote sessions now connect through your TURN server (coturn or a Cloudflare TURN key) instead of falling back to **Live (via hub)** whenever the PC is not on your own network. The browser had been rejecting every network address the PC sent after its first one, including its address on the TURN server, so only a PC on the same LAN could ever connect directly
* **remote:** a network address the browser rejects is now logged in the browser console instead of being dropped without a trace

### Notes

* No agent update is needed. The hub corrects what every agent already in the field sends
* Remote now shows **Live** rather than **Live (via hub)** for a PC on another network, as long as a TURN server is configured. With no TURN server, the hub relay still takes over as before
