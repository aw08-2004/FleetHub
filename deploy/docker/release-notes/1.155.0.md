## 1.155.0 (2026-10-19)

### Features

* **patches:** a maintenance window can **install approved updates automatically**. When it opens, the hub starts one run for every covered machine with approved updates, which restarts them according to the window's restart policy. Off by default, existing windows included: tick it on each window that should patch by itself
* **patches:** a maintenance window can make **FleetHub the only thing that installs updates** on its machines. The agent turns off Windows' own automatic updates and hides Install in Settings, so only approved updates install, during a run. Needs agent 3.47.0. Machines whose Windows Update is set by Group Policy or Intune are left alone and listed as such. Off by default
* **patches:** the Patches page shows who installs updates on each machine, and lists updates that were installed outside FleetHub

### Bug Fixes

* **patches:** the Approved tab and the empty Runs tab now say that approving an update does not install it by itself (#140)
