## 1.172.0 (2026-10-30)

### Features

* **group policy:** a policy can now set **Administrative Templates**, the settings Windows' Local Group Policy Editor (`gpedit.msc`) shows. In the policy editor, **Browse templates…** opens the same tree: *Computer Configuration* and its categories on the left, the settings on the right, and for each setting **Enabled**, **Disabled** or **Not configured**, its options and its help text. Search finds a setting by name
* **group policy:** the templates come from your own PCs. A Windows agent that supports them sends its `C:\Windows\PolicyDefinitions` (English, German and Spanish) once per Windows build, and every other PC on that build shares the same set. When PCs run different builds, pick the set at the top of the browser; the one most of your PCs run is selected first
* **group policy:** the resultant set of policy lists the template settings that apply to a PC, which policy won each one, and names the template setting beside each registry value it writes

### Notes

* **Nothing changes on a PC until you save a template setting in a policy and link it.** A template setting is saved as the registry values it writes, under the same rules as values you type in: only under `HKLM\SOFTWARE\Policies`, never over a value FleetHub did not write
* The template browser stays empty until a PC sends its templates, which needs the **next Windows agent release**. Deploy this hub first, as always. Policies, links and typed registry values work as before with every agent
* Settings that write outside `HKLM\SOFTWARE\Policies`, or use a QWORD value, are listed greyed out with the reason, and cannot be set
* **User Configuration** is shown but cannot be set yet: it needs an agent that writes the PC's local Group Policy, which is planned next
* Some settings delete a value when **Disabled**. FleetHub does not delete values yet; it only removes values it wrote itself. The resultant set marks such settings
* A policy cannot set one registry value twice, whether by a template setting and a typed value or by two template settings. Saving such a policy is refused with both names
