## 1.170.1 (2026-10-29)

### Bug Fixes

* **hub:** the hub now requires **Authlib 1.9.1** or later. Authlib 1.8.0 has published advisories that let a forged token signature pass, and the hub uses Authlib to check the token Google or your OIDC provider sends back at sign-in
* **hub:** the hub now requires **certifi 2026.10.23** or later, which removes the emSign root certificates whose intermediate keys were compromised. The hub uses this bundle to check TLS when it fetches a web page on your behalf

### Notes

* **This is the update that actually moves an installed hub to those versions.** Until now the hub listed both packages without a version, and a self-update only installs what is missing, so a hub that already had Authlib 1.8.0 kept it. On this update the hub upgrades both packages before it restarts
* A hub that cannot reach the Python package index holds this update back until it can
* Docker: the image already carried both versions since 1.170.0. It also picks up `python-engineio` 4.15.1
* Nothing changes in the console, the agents or the desktop client
