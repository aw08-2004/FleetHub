## 1.150.0 (2026-10-15)

### Features

* **remote:** drive the remote viewer from a phone with a virtual cursor. One finger moves the cursor by the finger's travel, a tap clicks where the cursor is, two fingers tapped right-click, hold-then-drag moves a window; pinch zooms the picture, not the page, and two fingers pan it (#136) (c1539f7)
* **remote:** give iPhone a fullscreen. Safari on iPhone has the Fullscreen API on `<video>` only, so the button did nothing; the stage is now pinned over the page and the console's frame is lifted over the sidebar and topbar. iPad takes the native prefixed path (#136) (c1539f7)
