## 1.177.0 (2026-11-02)

### Features

* **onboarding:** an enrolled machine can run its onboarding script again without an operator revoking it first -- to repair the agent, or to bring back one that has gone offline. The script sends the credential the agent already holds, and the hub replaces it with a new one and revokes the old one in the same step. Before, the name was refused as *already enrolled*

### Notes

* Only the machine's own, still-valid credential counts. A machine whose credential was lost or revoked, and any other machine under that name, is refused as before: revoke the old agent in the console, then run the script again
* The replacement appears in the Audit Log as a *revoke_agent* line for the old agent id, next to the *onboarding.redeem* line that names it
