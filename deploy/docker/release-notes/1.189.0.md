## 1.189.0 (2026-11-24)

### Features

* **dashboard:** the Dashboard is now a **bento grid**. A large *Fleet health* tile shows online against offline as a ring with the machine count in the middle, next to *Not enrolled*, *Open alerts* and *Agents behind*. Five smaller tiles sit around it: CPU temperature (average, hottest, over the threshold), CPU load, free disk space, what is happening now, and operating systems as one stacked bar. Every number the old sections showed is still there
* **machine:** a machine's **Overview** is a bento grid too. CPU load and live temperature are ring gauges, GPU and memory are bars, and everything that describes the PC (model, serial, service and asset tag, OS, OU, agent version, uptime, channel) is in one *Device profile* tile on the right
* **machine:** the rest of the Overview is tiles too, with no section headings. **Storage**, **Cooling**, **Security posture** and **Drive encryption** sit in a grid under the live tiles. Security posture is a checklist with a tick or a cross per check, failed checks first, and drive encryption shows a lock per drive. History, Processes, Location, Apps, Usage, Sensors, Machine settings and Lock and wipe are full-width tiles that still fold open and closed, and Lock and wipe is now always last
* **machine:** **History** is a grid of compact metric cards, one for every metric the PC reports. Each card shows the latest value, how it compares with the average over the visible range, a filled chart with the peak marked, and the minimum and peak with its time. The expand button opens the full chart with axes. Zooming still moves every card together
* **machine:** History has **Live, 1 h, 6 h, 24 h, 7 d and 30 d** buttons next to the day picker. Live to 24 h keep following new readings. 7 d and 30 d show the past week or month as 15-minute and hourly averages and refresh when you choose a range or reset the zoom. Choosing an earlier day shows that whole day. Over a range longer than a day, the peak shows its date as well as its time
* **history:** **15m** and **1h** are new resolutions. A history request spanning more than eight days with automatic resolution now gets 1h buckets instead of 5m, and a multi-day request reads each day's CSV archive the way a single-day request always has (up to 31 days per request)
* **machine:** a **Memory** tile shows how full the PC's memory is, with used and total GB
* **machine:** serial, service tag, asset tag and OU have a **copy** button. The OU copies the full distinguished name

### Bug Fixes

* **machine:** cards no longer jump between rows from one PC to the next. A desktop that reports CPU clock and power and a laptop that does not now have the same layout: a missing reading hides one line, not a whole card
* **machine:** a long Active Directory OU no longer runs out of its card. It reads as a path (`ccmf.com.py / FILADELFIA / PC_WSUS_TEST_W10`), and the full DN is shown when you hover over it

* **machine:** choosing a different time range while History was still loading was sometimes ignored. The newest request now always loads

### Notes

* Nothing to do for agents: the Overview uses readings every agent already sends. The Memory tile appears only on machines that report memory load
