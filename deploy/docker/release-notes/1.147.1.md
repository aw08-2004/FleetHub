## 1.147.1 (2026-10-13)

### Bug Fixes

* **devices:** stop a deleted PC coming back as "Online, not enrolled". A delete used to wipe readings and the machine record before removing the agent, and a report that had already passed its token check wrote the record straight back once the delete committed, leaving a record with no agent behind it to delete a second time. The delete now removes the agents first, and the delete and `/api/report` share a per-machine gate, so a report either finishes before the agents go or is refused (#128) (1c5dee4)
* **devices:** drop a deleted machine's queued readings inside the write transaction, so they cannot be written back after the delete (#128) (7b92872) (36b28aa)
