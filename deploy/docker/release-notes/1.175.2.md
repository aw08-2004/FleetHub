## 1.175.2 (2026-10-31)

### Bug Fixes

* **onboarding:** a PC whose BIOS has no real serial number (it reports *System Serial Number* or *Default string*) can be onboarded again after its record is deleted. Before, the installer started the agent before it used the code, and the agent's first report put the record straight back, so every run ended in *this PC could not be matched to it*. For an hour after you delete a machine, the hub now ignores reports from that name unless they come from an enrolled agent. A PC you delete and do not re-onboard reappears after that hour if its agent is still running, as it always did
* **devices:** deleting a machine now also removes an enrollment stored under a different capitalisation of its name (`desktop-x` for `DESKTOP-X`), which had kept refusing its onboarding code as *already enrolled*

### Notes

* No agent update is needed
