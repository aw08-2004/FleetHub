## 1.175.0 (2026-10-30)

### Features

* **rules:** a rule can now test a laptop's or Android device's **battery charge**. The new variable **Battery charge** (`metric.battery_pct`, 0–100) makes an alert such as `metric.battery_pct < 70` possible, and the rules assistant can draft one
* **machine page:** laptops and Android devices get a **Battery** history chart beside CPU, memory and power. Desktops do not show it
* **settings:** *History Metrics* has **Record battery charge** and **Keep battery history for**, which work like the other metrics' pair

### Notes

* A machine without a battery reads *unknown* for Battery charge, so a battery rule never fires on a desktop
* The value is the battery's charge level as the agent already reports it. The battery's wear level is a separate reading and is never used as the charge
* **No agent update is needed.** Windows agents already send their battery sensors, and Android agents already send the charge level. History starts with this hub version
