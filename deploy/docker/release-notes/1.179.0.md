## 1.179.0 (2026-11-14)

### Features

* **files:** select one or more folders in the Files tab and choose *Send to another computer…* from the right-click menu. The folders are copied live, through the hub, into a folder you pick on another PC you manage (default `C:\Incoming`), each under its own name. There is no size limit: the hub holds only a few megabytes at a time and the copy runs at the speed of the slower PC. Nothing on the source PC changes, files already on the target are kept rather than replaced, and a file the source could not read (one open exclusively, such as an Outlook .pst in use) is skipped and named in the result. Progress shows under the file list with a *Cancel copy* button. **Both PCs need agent 3.51.0 or newer**; older PCs are listed but greyed out
* **files:** *Back up…* in the same menu takes a one-off backup of the selected folders to the backup destination. It is kept apart from the scheduled backups: it does not move the next scheduled run, the next scheduled backup does not build on it, and it is rotated separately, so it never pushes a real generation out of storage. The policy's excludes still apply. It needs the *manage_backups* permission and appears on the Backup tab's run list like any other run
* **sidebar:** *Tickets* shows the number of open tickets (new, open or waiting) on the PCs you can see, the same way *Alerts* does, and updates live
