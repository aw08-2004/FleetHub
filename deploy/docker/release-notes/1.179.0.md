## 1.179.0 (2026-11-14)

### ⚠ BREAKING CHANGES

* **rollout:** *Send to another computer* needs agent 3.51.0 or newer on **both** PCs. Deploy this hub first, then the agent. Until a PC has updated it is listed in the target list greyed out, with its agent version. The one-off folder backup and the Tickets badge need no agent update ([#207](https://github.com/aw08-2004/FleetHub/pull/207)) ([b27d828](https://github.com/aw08-2004/FleetHub/commit/b27d828))

### Features

* **files:** copy one or more folders live to another PC you manage: tick them in the Files tab, right-click, *Send to another computer…*. Each lands under its own name in the folder you pick (default `C:\Incoming`), with no size limit. Nothing on the source changes, files already on the target are kept, a file the source cannot read (an Outlook .pst in use) is skipped and named in the result, and progress shows under the file list with *Cancel copy* ([#207](https://github.com/aw08-2004/FleetHub/pull/207)) ([b27d828](https://github.com/aw08-2004/FleetHub/commit/b27d828))
* **backups:** take a one-off backup of the folders ticked in the Files tab with *Back up…* (needs *manage_backups*). It is a full backup kept apart from the schedule: the next scheduled run keeps its time and does not build on it, and rotation never removes a scheduled generation to keep it. It shows on the Backup tab as a *selection* run and restores like any other ([#207](https://github.com/aw08-2004/FleetHub/pull/207)) ([b27d828](https://github.com/aw08-2004/FleetHub/commit/b27d828))
* **sidebar:** show the number of open tickets (new, open or waiting) beside *Tickets*, counted only on the PCs you can see, and keep it current without a reload, as *Alerts* does ([#207](https://github.com/aw08-2004/FleetHub/pull/207)) ([b27d828](https://github.com/aw08-2004/FleetHub/commit/b27d828))
