## 1.180.0 (2026-11-15)

### ⚠ BREAKING CHANGES

* **rollout:** sending or backing up a **file** from the Files tab needs agent 3.52.0 or newer on the PC the file is on. Deploy this hub first, then the agent. On an older agent the console says so when you pick a file, and folders keep working as before; the PC receiving a copy only needs 3.51.0

### Features

* **files:** *Send to another computer…* and *Back up…* now work on any selection in the Files tab: files, folders, or both at once. A file lands directly in the destination folder; a folder lands under its own name, as before
