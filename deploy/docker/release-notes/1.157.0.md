## 1.157.0 (2026-10-20)

### Features

* **tickets:** the ticket page's AI triage button is now **Ask the assistant**. It opens the assistant in a new conversation and sends it the ticket number, link, subject, description, urgency, status and the machine facts -- never the screenshots or who reported it -- so follow-up questions, checks on the PC and any drafted script happen in one place. The separate inline triage box and its "Draft script (switched off)" button are gone. The button shows only while the assistant is switched on, for operators who can manage tickets
