## 1.185.0 (2026-11-24)

### Bug Fixes

* **active directory:** AD sync can now trust your own certificate authority. A domain controller whose LDAPS certificate comes from AD Certificate Services failed every sync with *CERTIFICATE_VERIFY_FAILED … unable to get local issuer certificate*, and no setting could fix it. Set **Settings → Active Directory → CA certificate** to a PEM file with your root CA, e.g. `/state/ad-ca.pem` in Docker. It can be the same file as the sign-in page's CA certificate

### Notes

* Leave the field empty if the DC's certificate is from a public CA. Nothing changes for an existing setup until the field is filled in
* If you worked around the error by setting `SSL_CERT_FILE` in the host `.env`, remove that line once the CA certificate is set, and recreate the container
