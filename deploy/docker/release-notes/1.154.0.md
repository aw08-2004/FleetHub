## 1.154.0 (2026-10-19)

### Features

* **sidebar:** the "Hub vX is available" notice links that version's release notes
* **sidebar:** a second notice announces each new agent release on the fleet's channel, with a link to its GitHub release. It is a notice, not an approval: agents still install the release on their own within about 15 minutes. Dismissing it hides it until the next agent release
* **docker:** `deploy/docker/example.env` is a template for the hub's bootstrap settings, and the compose file now reads `deploy/docker/.env` through `env_file:`. Copy the template to `.env` before `docker compose up`; compose refuses to start without it

### Documentation

* **docker:** installation guide explains the two `.env` files: `deploy/docker/.env` on the host for bootstrap values, and `/state/.env` on the volume for everything the Settings pages save. Keep sign-in, TURN, AI, directory and backup-key values out of the host file, or a console change will revert on the next recreate
