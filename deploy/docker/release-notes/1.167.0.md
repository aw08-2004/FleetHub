## 1.167.0 (2026-10-23)

### Features

* **map:** the device map is **live**. While it is open, every online device you may locate is asked for its position again every minute and its point moves as the answer arrives. A *Live* switch beside the device count pauses it. Nothing is asked while the page is closed, in a background tab or paused
* **map:** every located device in the list beside the map now has its own **Locate** button. Until now the button only appeared on devices that had never been located, so a device could be located from the map once and its point never moved again
* **settings:** **Settings → Location → Live map refresh** sets how often the live map asks (60 seconds by default, 15 at the least). The spacing is per device, so several people looking at the map at once do not ask a phone any more often

### Notes

* Each live ask is a normal locate: it is audited under *locate_device* (marked as live) and the device shows its notice naming who asked. With the next Android agent the notice is replaced quietly rather than sounding every minute.
* Offline devices are skipped instead of being sent a request that would only expire, so their history is not filled with *did not answer* rows.
* Location history fills faster on a map left open. The 100-positions-per-device cap and **Keep location history for** still apply.

Works with every Android agent already installed. Turning a phone's location back on when a locate finds it switched off needs the next Android agent release.
