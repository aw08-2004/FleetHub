## 1.165.0 (2026-10-22)

### Features

* **remote:** a TURN relay the hub does not run can now be used for remote sessions. **Settings → Remote Control** has a *Provided ICE servers* box: paste an `iceServers` JSON block with a fixed username and credential (for example the answer from Cloudflare's `generate-ice-servers`) and every session gets it as-is. Credentials generated by Cloudflare stop working after the TTL they were generated with
* **remote:** or save a **Cloudflare TURN key** (key ID + API token) and the hub asks Cloudflare for a fresh credential for every session, so nothing expires. *Test* checks the key. If Cloudflare cannot be reached, the session still starts with the other servers
* **remote:** the TURN status card counts the provided servers, and they are included in *ICE servers per session*. Both are kept in the hub's `.env` and never shown again after saving

No agent update needed.
