## 1.171.0 (2026-10-29)

### Features

* **backups:** backups can now run **at set times** instead of every N hours. On **Fleet tasks → Backup**, **When to back up** offers *Every N hours* (as before), *At set times* (pick days and one or more times, e.g. Mon–Fri at 02:00) or a *Cron expression* (e.g. `0 3 * * 0` for Sundays at 03:00). The hub database and PC files each have their own schedule
* **backups:** under the picker, **Next runs** shows the next five runs in the hub's time, with its UTC offset, so what you see is when the hub will actually run it, whatever time zone your browser is in

### Notes

* **Nothing changes until you pick set times.** Every hub keeps its current interval after this update
* A run missed while the hub was down, or while a PC was switched off, runs **once** when it is back, not once for every missed slot
* A hub that has never backed up still takes its first backup as soon as backups are turned on, not at the first scheduled time
* No agent update is needed
