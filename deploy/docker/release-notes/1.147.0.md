## 1.147.0 (2026-10-13)

### Features

* **remote:** tell the viewer why there is no picture. When the helper's Windows session has no rendered desktop (disconnected or signed out), the stall now reaches the hub-relay viewer as well as a WebRTC peer that never connected, carries `reason: no_display`, and points at the Session picker. Needs agent 3.44.0 on the PC; an older agent shows the generic stall (#127) (cf80c2e)
* **installer:** refuse 32-bit Python for the hub, say so when a reinstall finds one, and prefer a machine-wide interpreter over a per-user one. A 32-bit hub has a 2 GB address space and throws `MemoryError` under load (#127) (4278199) (fb4e822)

### Bug Fixes

* **assistant:** tell the assistant where the agent logs live, and stop a recording's `badge_timeout` message blaming only the agent (#127) (8edebef)

### Documentation

* Deploy this version before agent 3.44.0, which depends on 1.146.0 (uninstall on delete), 1.144.0 (signed telemetry) and this version (the "no display" hint).
