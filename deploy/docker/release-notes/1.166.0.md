## 1.166.0 (2026-10-23)

### Features

* **fleet:** agent updates can be **pinned to an exact version** for each platform. **Settings → Fleet** has *Windows / Linux / Android agent updates* (Automatic or Pinned to a version) with a version box beside each one. A pinned platform installs exactly that version, forward or back, and nothing newer. Pinning at the version the fleet already runs turns automatic updates off, so a release can be reviewed first. Raise the pin to approve it
* **fleet:** while Windows is pinned, the sidebar's new-agent notice says the release is waiting for review instead of saying it is installing
* **fleet:** a beta machine now **follows a newer stable**. If a stable release passes the newest beta (a stable-only hotfix, for example), beta machines install it, and they go back to beta when a newer beta comes out. The machine page says when this is happening
* **machine:** the release-channel line says when a pin applies, when the agent is too old to honour one, when the pinned version has no signed release, and when an Android device cannot go back to an older build

### Notes

* A pin only binds agents that understand it: Windows **3.49.0**, Linux **0.4.0** and Android **0.4.0** and later. Older agents keep updating automatically until they reach those versions, so leave the fleet on Automatic until they have.
* Only versions released from now on can be pinned to, because each release now also publishes a signed manifest for that one version. Older versions can't be selected unless a manifest is added for them.
* Android cannot install an older build. A pin below the version a device runs keeps it where it is.

Needs the agent releases above for pins to take effect. The beta-follows-stable change works with every agent already installed.
