## 1.148.0 (2026-10-13)

### Features

* **processes:** accept both `FleetHubAgent.exe` and `TempMonitorAgent.exe` on the Processes card's kill-protection list, so the agent cannot be ended from the console under either name. A fresh install from `main` gets the new exe name while still running a 3.44.0 build that only knows the old one, which is why the hub's list matters most (#129) (5d31c5d)

### Documentation

* The installer renames the exe, self-update does not, so a PC nobody re-installs keeps `TempMonitorAgent.exe`. The agent side of this change is in `main` and not yet in a release; see ROADMAP.MD, *Agent exe renamed to `FleetHubAgent.exe`*.
